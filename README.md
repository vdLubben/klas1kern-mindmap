# 🌋 Kernzinnen & Woordspin (Mindmap) - Brugklas Lesmodule Vulkanen

Een interactieve HTML-lesmodule speciaal ontworpen voor **brugklasleerlingen**. Leerlingen leren eerst hoe ze de **kernzin** uit een alinea herkennen aan de hand van een boeiende tekst over **Vulkanen**, waarna ze deze kernpunten visueel verwerken in een woordspin/mindmap conform de 7 gouden mindmap-regels.

---

## 🌟 Belangrijkste Functionaliteiten

1. **🎯 Les 1: Kernzinnen Herkennen (Vulkanen)**:
   - **Goudzoeker Uitlegkaart**: Visuele tips voor brugklasleerlingen (*Kijk naar eerste/laatste zin, stel de hoofdvraag, filter voorbeelden weg*).
   - **Kortere, toegankelijke leestekst**: *"Vulkanen: Vurige Bergen op Aarde"* (4 heldere alinea's: Wat is een vulkaan?, Hoe ontstaat een uitbarsting?, Typen vulkanen, Nut & Gevaar).
   - **Interactieve Markeerstift**: Groen voor kernzinnen, geel voor signaalwoorden, blauw voor weetjes.
   - **Kernzin Oefening**: Meerkeuze-vragen per alinea.

2. **🧠 Les 2: De 7 Mindmap Regels**:
   - Visuele uitleg van de 7 regels.
   - Geannoteerd praktijkvoorbeeld van de "Aarde" mindmap + kennisquiz.

3. **✍️ Les 3: Woordspin / Mindmap Maker Studio**:
   - Interactieve SVG mindmap builder met de Vulkanen-preset (Centraal: 🌋 Vulkanen; Takken: *Opening*, *Uitbarsting*, *Typen*, *Nut & Gevaar*).
   - Realtime 7-Regels Checker.

4. **📥 Download PDF Rapport (Altijd beschikbaar rechtsboven)**:
   - Een opvallende rode knop **"Download PDF"** rechtsboven die op **elk gewenst moment** door de leerling aangeklikt kan worden.
   - Exporteert de naam, klas, gekozen kernzinnen én een snapshot van hun gemaakte Vulkanen-mindmap.

---

## 🚀 Publiceren via GitHub Pages

1. Maak een repository op [GitHub.com](https://github.com) aan.
2. Upload alle bestanden uit de map `Tekststructuur_Mindmap` (`index.html`, `styles.css`, `app.js`, `mindmap.js`, `README.md`).
3. Ga naar **Settings** -> **Pages** en stel de bron in op de `main` branch.
